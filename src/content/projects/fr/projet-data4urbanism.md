## Le défi

Le projet Data4Urbanism étudie les modalités de transport dans la région de Strasbourg. Son objectif est de réunir dans une même visualisation les données de mobilité, les données météorologiques et celles sur la qualité de l’air.

## Les objectifs

- Traiter les données issues des flux RSS disponibles.
- Filtrer les données bruitées.
- Observer la mobilité dans l’agglomération.

## Les outils et le cadre

Les développements sont réalisés principalement en Python. Les travaux décrits sur le site historique s’inscrivent dans le stage de fin d’études du master CSMI de Xinyue Yang, avec un financement PEPS AMIES, CNRS.
